# Style references

Photos of ancient art to give the image tools as a style reference (see [design/prompts/advisor-figures.md](../../../prompts/advisor-figures.md)). Files starting `vase-A` are for style A (red-figure vase), `vase-black-figure` is the simpler black-figure style, and `fresco-B` is for style B (Etruscan wall painting). The game does not use this folder.

**How to use:** attach one picture (the Berlin Painter's singer is the best start) to your prompt: in ChatGPT, "in the style of this image"; in Midjourney, `--sref` with the picture's link. For the robed advisors try the judge; for Antistius, the hoplite.

All images come from Wikimedia Commons and may be reused. The ones marked CC BY or CC BY-SA need the photographer's credit if they are ever shown in public (for example in a post); the CC0 and public-domain ones need nothing. Each licence links to its Commons page.
